# =============================================================================
#  Domestic (mainland China) domain suffixes.
#
#  The auto-learner must NEVER route these through a proxy, no matter how many
#  direct connections to them fail. They are telemetry / background endpoints
#  that time out routinely, and proxying them makes them slower while consuming
#  the metered 50 GB plan.
#
#  Why a curated list instead of something clever:
#    * SmartDNS's audit was tried first. Its "lookup_source" column only says
#      "Server: china" for a non-cached answer, so a tail of 8000 rows yielded
#      just 36 domains - and missed exactly the offenders we care about
#      (doubao.com, zijieapi.com, aliyuncs.com were all absent because they were
#      served from cache).
#    * IP geolocation would work but needs a maintained CIDR database.
#  So: a small, explicit, easy-to-extend list. Add to it when review shows the
#  learner proposing something that should stay local.
#
#  Format: one suffix per line. '#' starts a comment. Blank lines ignored.
#  A .cn TLD is always treated as domestic and does not need to be listed.
# =============================================================================
