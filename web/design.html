Mihomo toolkit: native architecture

Toolkit 0.0.3 source design, reviewed 2026-11-07. This page describes ownership and traffic boundaries; it is not a live network-health report.

One owner per boundary

ComponentResponsibility
MihomoOrdered rules, proxy groups, chosen flow path and configured DNS.
Windows / ICSNative routing and a shared hotspot uplink. The SSID HypoMux does not imply an external HypoMux engine.
Adaptive dispatcherBounded allocation using configured priors and health; passive rates do not learn physical capacity.
Recovery helpersGuarded identity/address/route work, process supervision and diagnostics with separate lifecycles.
Provider applicationsRequest admission, protected keys, source/data quality and publication; no trading or acquisition permission is inferred here.

Policy is not current state

The main template binds the mixed proxy to loopback and disables its TUN. The separate optional cloud tunnel installs destination host routes and depends on a private main-engine egress listener. A running listener, healthy probe or unit-test pass does not prove authenticated application success.

Failover affects later choices after detection; it cannot bond one TCP session or preserve a connection whose adapter disappeared. Shared-adapter exclusion during regenerated policy remains a known design gap. Inspect actual ICS ownership and saved selectors before an authorized change.
